# v1.0.6 - SonarQube Cloud Coverage Import

## Summary

SonarQube Cloud now reports line coverage for the router scripts, using the same
merged kcov data that CI already gates at ≥90%. The router scripts behave exactly
as they did in v1.0.5.

## What Changed

- Added [`tools/cobertura_to_sonar.py`](../../tools/cobertura_to_sonar.py). It turns
  the merged kcov Cobertura report into SonarQube generic test coverage XML with
  repository-relative paths.
- The `coverage-report` job in [`ci.yml`](../../.github/workflows/ci.yml) converts the
  report and uploads it as the `sonar-coverage` artifact. The `sonarqube` job now
  runs after `coverage-report` and imports that file.
- [`sonar-project.properties`](../../sonar-project.properties) sets
  `sonar.coverageReportPaths` and limits Sonar coverage to the shipped scripts
  (`tools/**` and `.github/**` are excluded).
