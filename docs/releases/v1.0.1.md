# v1.0.1 - Quality and CI Hardening

## Summary

This release hardens repository quality gates and CI reproducibility for Synology SRM shell automation.
It introduces mandatory local/CI formatter and linter checks, explicit pinning for tooling and workflow dependencies, and stronger deterministic test execution support.

## Highlights

- Enforced mandatory quality gate order: format -> lint -> tests -> coverage validation.
- Enforced 140-character max line length for non-Markdown files.
- Enforced no suppression directives policy via dedicated checks.
- Added centralized local quality runner: tools/runners/quality.sh.
- Hardened CI workflow with pinned actions and stricter quality stages.
- Expanded deterministic test tooling and Docker test environment reliability.
- Added comprehensive Copilot repository governance files (instructions, prompts, agents, skills, hooks).
