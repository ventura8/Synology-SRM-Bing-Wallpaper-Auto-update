# v1.0.2 - TLS Hardening and Temp Symlink Race Fixes

## Summary

This release closes MITM and local symlink-race risks in the installer and daily
wallpaper path by restoring TLS certificate verification on all `wget` calls,
rejecting downloads that lack a JPEG SOI prefix before ImageMagick/system writes,
isolating temp files in a private `mktemp` workdir, caching overlay fonts outside
world-writable `/tmp`, and sanitizing archive dates.

## Why This Change

- Close CRITICAL risk: installer downloaded and executed the wallpaper script as
  root with `--no-check-certificate`.
- Close HIGH risk: daily cron downloads (Bing API, image, font) skipped TLS
  verification and fed untrusted image bytes into ImageMagick as root.
- Close MEDIUM risk: predictable `/tmp` paths allowed local symlink races.
- Close archive path traversal via unsanitized Bing `startdate`.

## What Changed

### 1. Installer TLS Verification

- Removed `--no-check-certificate` from [`install.sh`](../../install.sh).
- Fail closed on download/certificate errors; hint to update CA store or use
  `LOCAL_INSTALL_PATH` for offline install.

### 2. Daily Script TLS and Content Checks

- Removed `--no-check-certificate` from Bing API, image, and font `wget` calls in
  [`bing_wallpaper_auto_update.sh`](../../bing_wallpaper_auto_update.sh).
- Reject wallpaper URL paths that are empty, non-absolute, or contain `@`,
  `://`, or `..`.
- Reject downloads that do not start with JPEG SOI magic bytes (`FF D8 FF`)
  before ImageMagick or system copies (SOI prefix check only; not a full JPEG
  decoder validation).

### 3. Temp File Isolation and Font Cache

- Replace hardcoded `/tmp/bing_*` paths with `mktemp -d` workdir (`chmod 700`)
  and `trap` cleanup.
- Cache overlay font under root-owned `/usr/local/share/bing-wallpaper/`.

### 4. Archive Date Sanitization

- Archive filenames use `SAFE_DATE` (exactly eight digits) instead of raw
  `startdate`.

### 5. Tests and Coverage

- Updated BATS mocks/assertions for TLS flags, JPEG magic, and font cache path.
- Restored `SET_WELCOME_MSG=false` after welcome-message test (trap cleanup).
- Coverage validated at **95.7%** (threshold **90%**); `assets/coverage.svg`
  refreshed.

### 6. Documentation and Governance

- Expanded root `AGENTS.md` and `.agents/skills/` for quality, pipeline, and
  install workflows.
- Documented TLS-required download behavior (never reintroduce
  `--no-check-certificate`).
- Added this release document: `docs/releases/v1.0.2.md`.

## Policy Guarantees Added by This Release

- TLS certificate verification stays enabled on installer and product downloads.
- Downloads lacking a JPEG SOI prefix never reach SRM wallpaper paths or
  ImageMagick processing.
- Temp intermediates live only under a private `mktemp` directory.
- Archive mode rejects non-`YYYYMMDD` dates.

## Notes

- If a router lacks a current CA bundle, update CA certificates or install via
  `LOCAL_INSTALL_PATH` rather than reintroducing `--no-check-certificate`.
